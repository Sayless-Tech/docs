Preferences control personal settings for your account. They affect your own experience without changing the workspace for everyone else.

## Overview

Use preferences after joining a workspace or when the interface does not match how you prefer to work.

Preferences are different from workspace settings. Workspace settings affect the team. Preferences affect you.

Go to [Settings \> Preferences](https://joinsayless.com/{workspace}/settings/preferences).

| Setting type | Scope | Use it for |
| --- | --- | --- |
| Preferences | Personal | Theme, display, and personal working behavior. |
| Workspace settings | Team-wide | Labels, statuses, members, billing, integrations, API access. |

## Appearance

Use appearance settings to make Sayless comfortable for daily work.

### Theme

Choose the theme that works best for your environment. This changes the visual appearance of the app for your account.

### Display behavior

Preferences can affect how dense or comfortable the interface feels, depending on the settings available in your workspace.

## Working behavior

Personal preferences are useful when you spend most of the day in the inbox, tickets, or record views.

### Navigation

Use keyboard shortcuts and the command menu for faster movement through the app. Press `?` to see available shortcuts.

> Preference changes only affect your own account. If a teammate sees a different layout or behavior, ask them to check their own preferences.

### Editor behavior

Editor behavior applies where you write replies, descriptions, comments, notes, reports, and broadcasts.

## When to use workspace settings instead

Use admin workspace settings when you need to change shared behavior.

### Shared configuration

Labels, statuses, members, billing, login methods, and integrations are workspace-level settings. Changes there can affect everyone.
