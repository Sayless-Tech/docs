## Auth

Bearer `sl_api_…` / `sl_oat_…`.

## List / create

```bash
curl -X POST "$SAYLESS_API_URL/api/v1/companies/list" \
  -H "Authorization: Bearer $SAYLESS_API_KEY" \
  -H "Content-Type: application/json" \
  -d "{\"workspaceId\":\"$SAYLESS_WORKSPACE_ID\",\"limit\":25}"
```

```ts
const company = await sayless.companies.create({
  _id: crypto.randomUUID(),
  workspaceId,
  name: 'Acme',
  slug: 'acme',
  urlId: 'acme',
  website: 'https://acme.example',
  domains: ['acme.example'],
});
console.log(company.companyId);
```

Use `Idempotency-Key` on create. Nested CRM routes (notes, documents, folders, labels, sectors, …) live under `/api/v1/companies/…`.
