title: Messages API
description: List conversation messages and send, edit, or delete messages.
---

## Auth

Bearer `sl_api_…` / `sl_oat_…`.

## List

```bash
curl -X POST "$SAYLESS_API_URL/api/v1/messages/list" \
  -H "Authorization: Bearer $SAYLESS_API_KEY" \
  -H "Content-Type: application/json" \
  -d "{\"workspaceId\":\"$SAYLESS_WORKSPACE_ID\",\"conversationId\":\"$CONVERSATION_ID\",\"limit\":50}"
```

## Send

Honor `Idempotency-Key` on retries.

```ts
await sayless.messages.send({
  workspaceId,
  conversationId,
  messageId: crypto.randomUUID(),
  previousMessageId,
  senderId: me.profileId,
  statusId,
  channel: 'email',
  privateNote: false,
  subject: 'Re: Renewal',
  content: '<p>Thanks, we will review it.</p>',
  preview: 'Thanks, we will review it.',
  contentAttributes: {},
});
```

Every field above is required. `previousMessageId` is the message you are replying to, and `senderId` is your workspace profile (from `GET /api/v1/users/me`).


Also: `edit`, `delete`, `addReaction`, and `removeReaction`.
