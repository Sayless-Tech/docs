---
title: Attachments API
description: Upload and resolve file attachments for the work graph.
---

Attachment routes under `/api/v1/attachments` cover create-from-URL, multipart create/complete, delete, and content redirects.

Requires a workspace-scoped Bearer token. Prefer creating attachments before linking them from messages or tickets.
