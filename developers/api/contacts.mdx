title: Contacts API
description: Company contacts on the public CRM surface.
---

Contacts are nested under companies:

| Action | Path |
| --- | --- |
| List | `POST /api/v1/companies/contacts/list` |
| Create | `POST /api/v1/companies/contacts/create` |
| Info | `POST /api/v1/companies/contacts/info` |
| Update / archive / … | matching `/companies/contacts/…` actions |

```ts
const contact = await sayless.contacts.contactsCreate({
  _id: crypto.randomUUID(),
  workspaceId,
  companyId,
  firstName: 'Ada',
  lastName: 'Lovelace',
  username: 'ada',
  emails: ['ada@acme.example'],
});
console.log(contact.contactId);
```

Create needs `workspaceId`, `firstName`, `lastName`, and `username`. Send `Idempotency-Key` on create retries. List takes `workspaceId` plus [pagination](/developers/pagination).
