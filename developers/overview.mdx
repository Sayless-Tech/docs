## Start here

1. Create a personal API key in [Settings → API](/admin/api-and-webhooks).
2. Follow the [quickstart](/developers/quickstart) and list tickets.
3. Narrow the key with [scopes](/api-reference/scopes) if it should not have full access.
4. For a product other people install, use [OAuth](/developers/authentication) instead of a personal key.

## What you can build

| You want to | Use |
| --- | --- |
| Sync tickets or companies into another system | [Tickets](/api-reference/introduction) and [Companies](/api-reference/introduction) list/info routes, plus [webhooks](/developers/webhooks) |
| Post a reply or a ticket comment | Messages and ticket comments in the [API reference](/api-reference/making-requests) |
| Attach a file | [Upload a file](/developers/guides/upload-a-file) |
| Run a backend without a user present | OAuth app actor (`client_credentials`) in [Authentication](/developers/authentication) |

Billing, channel setup, broadcasts, triggers, analytics, and the customer portal admin stay in the Sayless app. The API does not expose them.
