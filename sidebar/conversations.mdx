The Conversations section is the main entry point for customer communication and follow-up work.

## Overview

The sidebar groups **Inbox** and **Tickets** together because they are usually part of the same workflow. A message arrives in the inbox, your team replies or triages it, and a ticket is created when the work needs tracking.

| Sidebar item | Link | Shortcut |
| --- | --- | --- |
| Inbox | [Inbox](https://joinsayless.com/{workspace}/inbox) | `G` then `I` |
| Tickets | [Tickets](https://joinsayless.com/{workspace}/tickets) | `G` then `T` |

## Inbox

Use the inbox for message threads from connected channels.

### Views

The inbox includes focused views such as All conversations, Assigned to me, Shared, Unassigned, and Snoozed.

> The sidebar item opens the inbox route. The inbox itself redirects to the All view when no specific view is selected.

### Common work

From the inbox you can reply, assign, label, update status, link a company, snooze, mark spam, and create tickets.

### Shortcut

Use `G` then `I` to go to the inbox.

## Tickets

Use tickets for follow-up work that needs ownership, status, comments, due dates, or links to Linear and Jira.

### Views

Ticket views include All tickets, My tickets, and Unassigned tickets.

### Common work

From tickets you can create new tickets, update properties, comment, link conversations, and manage external issue links.

### Shortcut

Use `G` then `T` to go to tickets.
