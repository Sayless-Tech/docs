Broadcasts are outbound messages sent through configured destinations.

## Overview

Use broadcasts when your team needs to send an announcement or update to a connected audience. Broadcasts have their own list, detail page, creation flow, edit flow, and management actions.

Go to [Broadcasts](https://joinsayless.com/{workspace}/broadcasts), or use `G` then `B`.

## Broadcast list

The broadcast list is where you review existing broadcasts and start new ones.

### Search and filters

Use search, filters, and sortable columns to find the broadcasts you need.

### Status

Broadcasts can have different states depending on whether they are drafts, sent, scheduled, canceled, or otherwise unavailable for editing.

| State | What it means | Common actions |
| --- | --- | --- |
| Draft | Message is not sent yet | Edit, send, delete |
| Sent | Message was delivered | View, duplicate |
| Canceled | Message was stopped | View, delete where allowed |

> Broadcast creation can require workspace Slack setup and the Enterprise plan. If creation is blocked, go to [Settings \> Slack](https://joinsayless.com/settings/slack) and review [Settings \> Billing](https://joinsayless.com/settings/billing).

## Broadcast actions

Available actions depend on the broadcast state and your permissions.

### Create and edit

Use **New broadcast** to draft a message. Open an existing broadcast to view details or edit when editing is allowed.

### Duplicate, cancel, and delete

Use menus from the list or detail view for management actions such as duplicating, canceling, or deleting broadcasts.

### Shortcut

Use `G` then `B` to go to broadcasts.
