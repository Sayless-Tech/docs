Reports help your team turn workspace data into views that are easier to monitor and discuss.

## Overview

The Reports sidebar item opens the reporting area. From there you can work with reports and dashboards.

Go to [Reports](https://joinsayless.com/{workspace}/reports), or use `G` then `R`.

| Object | Route pattern | Use it for |
| --- | --- | --- |
| Report list | `/{workspace}/reports` | Create and review reports. |
| Report details | `/{workspace}/reports/{reportPath}` | Open a specific report. |
| Dashboard details | `/{workspace}/reports/dashboard/{dashboardPath}` | Review a dashboard. |

## Reports

Reports are focused views of data.

### Report list

Use the reports page to create, search, filter, sort, open, and delete reports.

### Report details

A report detail page shows the report content and controls for the selected report.

## Dashboards

Dashboards group reports together.

### Dashboard details

Open a dashboard to view the reports and charts inside it.

### Dashboard navigation

Use dashboard navigation when moving through dashboards from the report area.

### Shortcut

Use `G` then `R` to go to reports.
