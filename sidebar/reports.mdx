Reports help your team organize related dashboard tiles into views that are easier to monitor and discuss.

## Overview

The Reports sidebar item opens the reporting area. From there you can work with reports and dashboards.

Go to [Reports](https://joinsayless.com/reports), or use `G` then `R`.

| Object | Route pattern | Use it for |
| --- | --- | --- |
| Report list | `/reports` | Create and review report containers. |
| Report details | `/reports/{reportPath}` | Arrange and review dashboard tiles in a report. |
| Dashboard details | `/reports/dashboard/{dashboardPath}` | Configure one dashboard tile. |

## Reports

Reports are containers for related dashboard tiles.

### Report list

Use the reports page to create, search, filter, sort, open, duplicate, share, and delete reports.

### Report details

A report detail page shows a grid of dashboard tiles. Users with update access can move and resize tiles, then save the report layout.

## Dashboards

Dashboards are individual chart or data-view tiles inside reports.

### Dashboard details

Open a dashboard to configure its data source, filters, visualization, interval, aggregation, sorting, and description.

### Dashboard navigation

Use the dashboard back button to return to the parent report or report list.

### Shortcut

Use `G` then `R` to go to reports.
