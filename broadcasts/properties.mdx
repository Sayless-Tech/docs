Broadcast properties help your team understand what was sent, where it went, who created it, and what state it is in.

## Overview

Use broadcast properties to find, filter, and review messages from the broadcast list and detail page.

Go to [Broadcasts](https://joinsayless.com/{workspace}/broadcasts).

| Property | Why it matters |
| --- | --- |
| Status | Tells whether the message can still be edited or sent. |
| Destination | Shows where the message is intended to go. |
| Sender profile | Shows who or what sends the message. |
| Created by | Shows who drafted the broadcast. |
| Sent time | Confirms delivery timing. |

## Broadcast properties

Properties vary based on broadcast state and destination.

### Status

Status shows whether a broadcast is a draft, sent, canceled, scheduled, or otherwise not ready to send.

### Destination

Destination shows where the broadcast is intended to go.

### Sender profile

Sender profile controls the identity used for the broadcast when profiles are configured.

### Created by

Created by shows who started the broadcast.

### Sent time

Sent time shows when the broadcast was delivered, when available.

## Filtering and views

Use the broadcast list to manage many broadcasts.

### Search

Search helps find broadcasts by visible content or metadata.

### Filters

Filters narrow the list by available broadcast fields.

### Columns

Columns make it easier to compare status, preview, date, and action fields.
