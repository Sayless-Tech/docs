Jira integration connects Sayless tickets to issue work managed in Jira.

## Overview

Use Jira when customer follow-up needs engineering, product, or operations work tracked in Jira.

Jira actions appear in ticket workflows when the integration is available and the ticket is active.

Start from [Settings \> Apps](https://joinsayless.com/{workspace}/settings/apps), then use Jira from a ticket detail page.

> Jira is available on the Free plan and all paid plans.

| Step | Where |
| --- | --- |
| Connect Jira | [Settings \> Apps](https://joinsayless.com/{workspace}/settings/apps) |
| Create a Sayless ticket | [Tickets](https://joinsayless.com/{workspace}/tickets) |
| Create or link Jira issue | Ticket detail metadata panel |

## Connect Jira

Jira is managed from Apps or Connected Accounts depending on your workspace setup.

### Personal connection

Connect your Jira account when Sayless needs permission to create or link issues on your behalf.

### Workspace requirements

An admin may need to enable or configure Jira before team members can use it.

> If Jira actions do not appear on a ticket, check that the app is connected and that you have permission to use it.

## Use Jira with tickets

Jira links keep external work connected to the original customer context.

### Create Jira issues

Create a Jira issue from a Sayless ticket when work should continue in Jira.

### Link Jira issues

Link an existing Jira issue when the work is already tracked there.

### Sync ticket context

Use the ticket title, description, linked conversations, and comments to preserve customer context.

### Remove links

Remove links when the external issue is no longer related to the ticket.
