Metric events are the individual data points collected for your metrics.

## Overview

Use metric events when you need to inspect raw activity behind a metric or troubleshoot incoming data.

Go to [Metrics \> Events](https://joinsayless.com/metrics/events), or use `G` then `E`.

> Metric events are available when the workspace has metric capacity. The Free plan has a metric-event limit of `0`; Startup includes up to `100,000` events, and Business and Enterprise are unlimited in the current client policy.

| Control | Use it for |
| --- | --- |
| Search | Find events by visible values. |
| Filters | Narrow events by fields. |
| Sort | Review recent or relevant data first. |
| Delete | Remove incorrect events. |
| View metric | Move from event data back to the metric. |

## View metric events

Metric events are available from the metric data area.

### Event list

The event list shows recorded metric data in a table.

### Event details

Event rows expose the fields available for that metric event.

### Event timestamps

Timestamps help you understand when activity occurred or was received.

## Manage events

Use event management tools carefully, especially in production workspaces.

### Search events

Search helps find events by visible values.

### Filter events

Filters narrow the event list by available event fields.

### Delete events

Delete an event only when it should be removed from the metric data.

### Bulk delete events

Use bulk delete when cleaning up several selected events.

> Deleting metric events changes the data available to charts and reports. Confirm you are removing test or incorrect data before using bulk delete.
