Metric properties define what the metric is, how it receives data, and how teammates understand it.

## Overview

Keep metric properties clear so data producers and report readers know what the metric represents.

## Metric properties

Metric properties appear in metric details, list views, forms, and integration modals.

### Name

Name is the primary identifier for the metric.

### Status

Status indicates whether the metric is active or receiving data.

### Event schema

The event schema describes the fields expected in metric events.

### Created by

Created by identifies who added the metric.

## Integration settings

Integration settings explain how data gets into the metric.

### Endpoint

Use the endpoint when sending metric data from an external system.

### Payload fields

Payload fields should match the event data your metric expects.

### Integration modal

Use the integration modal to review setup details for sending data to the metric.
