---
title: Support hours
description: Choose the weekly hours and holidays that SLA clocks and trigger delays use.
---

Support hours are the working schedule for the workspace. Open [Settings → Support hours](https://joinsayless.com/{workspace}/settings/support-hours).

Turn **Use support hours** on when [SLA](/admin/slas) time should count only inside that schedule. While it is off, SLA time is elapsed time, including nights and weekends.

Set the weekly intervals for each day, and add holidays for a year. Trigger delays that use business days or the support-hours clock follow this schedule.

If the plan does not include editing support hours, the current schedule stays visible and changes are unavailable until you upgrade.

## Chat widgets

Each [chat widget](/admin/chat-widgets) can reuse this workspace schedule, or turn on **Use widget-specific hours** and keep its own weekly windows.

The widget is always online when there is no schedule, or when the schedule is off. The server sends `{online, nextChangeAt}` so the messenger shows the offline message and the next opening time — sending is never blocked.
