Ticket details change as work progresses. Edit the ticket when the title, description, context, or outcome changes.

## Overview

Use the ticket detail page for ongoing work. It contains the title, description editor, comments, activity history, and metadata panel.

## Edit ticket content

Ticket content should stay useful after the first draft.

### Title

Update the title when the original summary no longer describes the work.

### Description

Use the description for the durable version of the task: what happened, what needs to happen, and any important links or decisions.

### Autosave

The ticket editor tracks changes while you work. Give long edits a moment to save before leaving the page.

## Manage ticket changes

Ticket changes are part of the ticket’s history.

### Unsaved changes

If you are editing a long description, confirm changes are saved before navigating away.

### Activity history

Activity history records important changes such as status, assignee, label, and relationship updates.

### Delete ticket

Delete a ticket only when the work should be removed. Deletion can be available from the detail page, row actions, or bulk actions depending on the view and permissions.
