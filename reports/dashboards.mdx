Dashboards organize reports together so teams can review related data in one place.

## Overview

Use dashboards when several reports should be viewed together.

The Reports route opens the dashboard list by default. Individual report details and dashboard details have separate routes.

Go to [Reports](https://joinsayless.com/reports).

> Dashboards are available on Startup and higher. The Free plan has a dashboard limit of `0`; Startup includes up to `9` dashboards, Business includes up to `50`, and Enterprise is unlimited in the current client policy.

| Dashboard action | Where |
| --- | --- |
| Create dashboard | Reports list |
| Open dashboard | Dashboard card or dashboard URL |
| Navigate dashboards | Dashboard detail header |
| Edit or delete dashboard | Dashboard menus |

## Work with dashboards

Dashboards can be created, opened, edited, navigated, and deleted depending on permissions.

### Create a dashboard

Create a dashboard when a team or workflow needs a shared reporting surface.

Dashboard creation may be limited by billing plan or workspace limits.

> Dashboard creation starts on the Startup plan. Admins can review [Settings \> Billing](https://joinsayless.com/settings/billing) if dashboard creation is unavailable.

### Open a dashboard

Open a dashboard to review the reports inside it.

Dashboard detail pages include navigation controls for moving between dashboards.

### Share a dashboard

Dashboard access follows the same permission model as reports: general access can make a dashboard visible more broadly, and member-specific access can grant named teammates Read, Read & Write, or Admin access.

| Permission | What it allows |
| --- | --- |
| Read | View the dashboard. |
| Read & Write | View and edit dashboard layout or contents. |
| Admin | View, edit, share, and delete the dashboard. |

Dashboards can also inherit practical visibility from the reports they contain. If someone can open a dashboard but cannot read a report inside it, they may need access to the underlying report as well.

### Navigate dashboards

Use dashboard navigation to move between dashboards from the report area.

### Delete a dashboard

Delete a dashboard only when it should no longer be available.

## Dashboard contents

Dashboard content is built from reports.

### Add reports

Add reports that belong together in the same review workflow.

Use dashboards to group reports by team, account segment, operational process, or leadership review.

### Arrange reports

Organize reports so the most important views are easy to scan.

### Empty states

If a dashboard is empty, add a report or create a new report first.

## Dashboard maintenance

Dashboards should stay useful as reporting needs change.

### Rename or edit dashboards

Update the dashboard name when its purpose changes.

### Remove outdated reports

Remove reports that no longer answer a current question.

### Delete unused dashboards

Delete dashboards that are no longer part of a team workflow.
